The visual system behind Brew & Co. — warm cream surfaces, a hand-pulled display face, and prices that read like they came off the till. Built for Next.js 16 + Tailwind CSS v4.

Color

Paper, ink, and one accent that talks.

Cream surfaces and espresso ink carry the page. Ember is the only color used for primary actions. Gold, pine, and berry identify menu categories — never actions.
